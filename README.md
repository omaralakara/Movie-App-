# 🎬 React Movie App

A modern, responsive movie discovery web application built with **React** and **Tailwind CSS**. This project fetches real-time data from the **TMDB (The Movie Database) API** to allow users to browse popular films and search for their favorites.

## 🚀 Features

- **Real-time API Integration:** Fetches live data including movie posters, titles, and release years.
- **Dynamic Search:** Instantly query the TMDB database to find specific movies.
- **Responsive Grid:** A "Cinematic" layout that adjusts perfectly for mobile, tablet, and desktop.
- **Secure Architecture:** Implements environment variables (`.env`) to protect sensitive API keys.

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **API:** TMDB API
- **State Management:** React Hooks (`useState`, `useEffect`)
